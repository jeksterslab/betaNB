# Estimate Cohen's f-Squared and Generate the Corresponding Sampling Distribution Using the Nonparametric Bootstrap

Estimate Cohen's f-Squared and Generate the Corresponding Sampling
Distribution Using the Nonparametric Bootstrap

## Usage

``` r
FSqNB(object, alpha = c(0.05, 0.01, 0.001))
```

## Arguments

- object:

  Object of class `nb`, that is, the output of the
  [`NB()`](https://github.com/jeksterslab/betaNB/reference/NB.md)
  function.

- alpha:

  Numeric vector. Significance level \\(\alpha\\).

## Value

Returns an object of class `betanb` which is a list with the following
elements:

- call:

  Function call.

- args:

  Function arguments.

- thetahatstar:

  Sampling distribution of \\(f^2\\) (column `fsq`) and the local
  \\(f^2\\) (one column per regressor).

- jackknife:

  Jackknife estimates.

- vcov:

  Sampling variance-covariance matrix.

- est:

  Vector of estimates.

- fun:

  Function used ("FSqNB").

## Details

Cohen's \\(f^2\\) for the whole model, \\(f^2 = R^2 / (1 - R^2)\\), and
the local \\(f^2\\) of each regressor, \\(f^2_j = sr^2_j / (1 - R^2)\\),
where \\(sr_j\\) is the semipartial correlation, are derived from each
bootstrap sample. Confidence intervals are generated by obtaining
percentiles corresponding to \\(100(1 - \alpha)\\%\\) from the generated
sampling distribution, where \\(\alpha\\) is the significance level.

## References

Selya, A. S., Rose, J. S., Dierker, L. C., Hedeker, D., & Mermelstein,
R. J. (2012). A practical guide to calculating Cohen's f2, a measure of
local effect size, from PROC MIXED. *Frontiers in Psychology*, *3*, 111.
[doi:10.3389/fpsyg.2012.00111](https://doi.org/10.3389/fpsyg.2012.00111)

## Examples

``` r
# Data ---------------------------------------------------------------------
data("nas1982", package = "betaNB")

# Fit Model in lm ----------------------------------------------------------
object <- lm(QUALITY ~ NARTIC + PCTGRT + PCTSUPP, data = nas1982)

# NB -----------------------------------------------------------------------
nb <- NB(
  object,
  R = 100, # use a large value e.g., 5000L for actual research
  seed = 0508
)

# FSqNB -----------------------------------------------------------------
out <- FSqNB(nb, alpha = 0.05)

## Methods -----------------------------------------------------------------
print(out)
#> Call:
#> FSqNB(object = nb, alpha = 0.05)
#> 
#> Cohen's f-squared (fsq) and local f-squared
#> type = "pc"
#>            est     se   R   2.5%  97.5%
#> fsq     4.1158 1.5440 100 2.4601 7.8713
#> NARTIC  0.9510 0.4070 100 0.3796 1.8343
#> PCTGRT  0.6019 0.2949 100 0.2230 1.2633
#> PCTSUPP 0.2909 0.2197 100 0.0457 0.8203
summary(out)
#> Call:
#> FSqNB(object = nb, alpha = 0.05)
#> 
#> Cohen's f-squared (fsq) and local f-squared
#> type = "pc"
#>            est     se   R   2.5%  97.5%
#> fsq     4.1158 1.5440 100 2.4601 7.8713
#> NARTIC  0.9510 0.4070 100 0.3796 1.8343
#> PCTGRT  0.6019 0.2949 100 0.2230 1.2633
#> PCTSUPP 0.2909 0.2197 100 0.0457 0.8203
coef(out)
#>       fsq    NARTIC    PCTGRT   PCTSUPP 
#> 4.1157764 0.9509843 0.6018924 0.2909455 
vcov(out)
#>               fsq     NARTIC     PCTGRT    PCTSUPP

#> NARTIC  0.4320177 0.16565182 0.03993109 0.02103005
```
